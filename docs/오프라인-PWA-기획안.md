# FestLock 오프라인(PWA) 기획안 — 제작 전 결정용

작성: 2026-11-15 · 대상: Tomorrowland Thailand 2026 (12/11~13, 현지 UTC+7) 먼저, 이후 다른 페스티벌로 확대
기술 타당성은 `Downloads/FestLock_오프라인PWA_기능요청서_2026-11-15.md` 검토 결과대로 "조건부 가능" (조건: 폰트 용량, iOS 실기기 확인).
이 문서는 "무엇을 어떻게 보여 주고 어떻게 받게 할지"를 정하는 기획안이다. **아직 코드는 만들지 않았다.**

## 1. 한 줄 정의
> 홈 화면에 앱처럼 추가하고 "오프라인 저장"을 눌러 두면, 현장에서 로밍이 꺼져 있어도 시간표 보기 · 라인업 담기 · 배경화면 만들어 저장이 된다.

## 2. 사용자 여정 (5단계)

| 단계 | 사용자가 하는 일 | 화면에 나오는 것 | 비고 |
|---|---|---|---|
| ① 발견 | TML 페이지를 연다 | 카드 모양 · 거꾸로 보기 줄 아래에 `📶 오프라인으로 쓰기` 칩 | 설치 전·후 모두 보임 |
| ② 설치 | 칩을 누른다 | 안내 시트: iPhone / Android 탭, 그림 3장, "추가한 뒤에는 **항상 아이콘으로** 열어 주세요" | Android 는 설치 버튼 한 번, iPhone 은 공유 → 홈 화면에 추가 |
| ③ 저장 | 아이콘으로 열고 `오프라인 저장`을 누른다 | 용량(예: 5.6MB) · "Wi-Fi 권장" · 진행률 바 · 완료 `저장됨 · 11/20 14:30 · 5.6MB` + `삭제` | 한 번 받으면 다시 안 받음 |
| ④ 현장 | 비행기 모드로 연다 | 상단 작은 배지 `오프라인 · 데이터 기준 11/20 14:30`. 영상 · 드랍 듣기 · 랭킹 숨김 | 배경화면 저장/공유는 그대로 |
| ⑤ 복귀 | 인터넷이 다시 된다 | 자동 갱신, 시간표가 바뀌었으면 토스트 `시간표가 업데이트됐어요` | 데이터 기준 시각이 바뀜 |

화면 스케치 (설치한 앱 안, 저장 전 → 저장 후):
```
┌ 카드 모양 [2 포토 글라스 ▾] [↕ 거꾸로 보기]
│ [📶 오프라인으로 쓰기 · 5.6MB]            ← 저장 전
│ [✓ 오프라인 저장됨 · 5.6MB · 11/20]  [삭제]  ← 저장 후 (누르면 상세)
```
```
오프라인으로 쓰기 (시트)
 ① 홈 화면에 추가    ← 설치 전에만 (iPhone/Android 탭)
 ② 사진·글꼴 저장    5.6MB   [저장]  ████░░ 62%
    □ 듀오톤용 큰 사진도 받기 (+3.5MB)
 저장하지 않으면: 사진 대신 이니셜 아이콘으로 나와요
```

## 3. 저장되는 것과 용량 (실측)

| 항목 | 용량 | 출처 |
|---|---|---|
| 앱 화면(JS/CSS) | 약 0.7MB (gzip 약 0.2MB) | FestLock 서버 (Vercel) |
| 글꼴 (현재 언어 기준) | 영어 · 태국어 약 0.4MB / 한국어 약 2.5MB / 번체 약 2.9MB / 간체 약 4.1MB / 일본어 약 4.6MB | 구글 폰트 조각 중 앱이 쓰는 글자를 덮는 것만 실측 합산 |
| TML 얼굴 사진 135장 + 별칭 15장 | 약 1.6MB | 사진 저장소(Blob) |
| TML B2B 두 사람 이미지 30장 | 약 0.9MB | Blob |
| TML 누끼 129장 (듀오톤 모양용) | 약 3.5MB | Blob |
| 튜토리얼 샘플 | 0.02MB | Vercel |
| **TML 팩 합계 (누끼 제외)** | **약 2.5MB** | |
| **TML 팩 합계 (누끼 포함)** | **약 6.1MB** | |

한국어 사용자가 누끼까지 받으면 앱 0.7 + 글꼴 2.5 + 팩 6.1 = **약 9.3MB**, 누끼를 빼면 **약 5.7MB**.

## 4. 비용·안전 (기획에 영향이 큰 부분)
- 사진 저장소(Blob)는 요금제 전송량 한도가 있다 (코드 주석 기준 Hobby 월 10GB — `src/blobHealth.ts`). 팩을 6MB 로 받으면 한도 안에서 약 1,700번, 누끼를 빼면 약 4,000번이다. 한도를 넘으면 **사진이 전부 안 뜬다** (경보 메일 장치는 이미 있음).
- 그래서 **자동 저장은 하지 않는다**: 사용자가 버튼을 눌렀을 때만 받고, 팩 버전이 같으면 다시 받지 않는다.
- 누끼(3.5MB)는 듀오톤 모양에서만 쓰므로 **기본은 제외**하고 선택 항목으로 둔다.
- 행사 직전에 사용자가 몰리면 위험하므로, 필요하면 Blob 요금제 상향 또는 팩 전용 사본을 FestLock 서버 쪽으로 옮기는 안을 쓴다 (요금표는 공식 문서로 다시 확인 필요).

## 5. iPhone 의 함정과 대응
- iPhone 은 **Safari 탭과 홈 화면 앱의 저장소가 따로**라서, Safari 에서 담은 라인업이 아이콘으로 열면 비어 있다.
- 1차 대응(안내): 설치 안내 맨 위에 "먼저 홈 화면에 추가하고, 아이콘으로 열어서 라인업을 담아 주세요" 를 크게 둔다. 설치 전에 이미 담은 라인업이 있으면 "아이콘에서는 다시 담아야 해요" 를 보여 준다.
- 2차 대응(선택): "내 라인업 옮기기" — 선택한 공연 목록이 담긴 링크를 만들어 아이콘에서 열면 가져오게 한다.
- 인스타·카톡 인앱 브라우저에서는 설치가 막히므로 기존 "기본 브라우저로 열기" 안내 끝에 "열린 뒤 오프라인으로 쓰기" 를 붙인다.

## 6. 오프라인에서 되는 것 / 안 되는 것
- 되는 것: 시간표 보기(날짜 · 무대 · 지금 공연 중), 라인업 담기/빼기와 겹침 팝업, 8가지 카드 모양과 미리보기, 아티스트 창, **배경화면 이미지 만들기 · 저장 · 공유**(글꼴이 저장돼 있어야 온라인과 똑같이 나옴).
- 안 되는 것(숨김): 영상, YouTube 드랍 듣기, 다운로드 수 · 아티스트 랭킹, 외부 듣기 링크. 집계 전송은 실패해도 조용히 넘어간다.
- 저장하지 않은 페스티벌은 사진 없이 이니셜 아이콘으로 나온다.

## 7. 데이터가 바뀌었을 때
- 온라인이 되면 새 버전을 받아 두고, 다음에 열 때 적용한다 (바로 바꾸면 보던 화면이 흔들리므로). 열려 있는 동안 새 버전이 있으면 `새 버전이 있어요 · 새로고침` 을 보여 준다.
- 팩은 파일 단위로 갱신한다: 새로 생긴 사진만 받고, 안 바뀐 것은 다시 받지 않는다.
- 문제가 생기면 스스로 등록을 해제하고 캐시를 비우는 파일을 다시 배포해서 되돌린다.

## 9. 완료 기준 (실기기)
1. 홈 화면에 추가 → 아이콘으로 열기 → TML 오프라인 저장 완료.
2. 비행기 모드에서 TML 시간표가 사진과 함께 나온다.
3. 오프라인에서 라인업을 담고 새로고침해도 유지된다.
4. 오프라인에서 만든 배경화면이 온라인과 같은 글꼴 · 사진으로 나오고 저장/공유된다.
5. 저장 안 한 페스티벌은 이니셜 아이콘으로 나오고 오류 화면이 없다.
6. TML 팩을 지우면 용량이 줄고 다른 페스티벌은 유지된다.
7. 온라인 복귀 시 최신 시간표로 갱신되고 기준 시각이 바뀐다.
8. 기존 사용자의 라인업은 업데이트 후에도 유지된다.

## 10. 결정할 것 (아래 "결정 기록"에 채운다)
1. 저장 방식: 버튼으로만 저장 / 설치하면 자동 저장
2. 누끼(+3.5MB): 기본 제외하고 선택 / 항상 포함
3. 적용 범위: TML 먼저 / 모든 페스티벌 동시
4. iPhone 라인업 옮기기: 안내만 / 옮기기 링크까지

## 결정 기록 (2026-11-15 확정)

| 질문 | 결정 |
|---|---|
| 저장 방식 | **버튼으로만 저장.** 사용자가 '오프라인으로 쓰기'를 누른 뒤에만 서비스워커를 켠다. 누르지 않은 사람에게는 아무 영향이 없다 |
| 사진·누끼 | **오프라인에서는 DJ 사진을 아예 쓰지 않고 이름만 보여 준다.** (사진·누끼·B2B 이미지는 저장하지 않는다) → 사진 저장소 전송량 걱정이 없어지고, 저장하는 것은 앱 화면과 글꼴뿐이다 |
| 적용 범위 | **TML 만 연다.** 구조는 페스티벌 공통이라 `src/offline.ts` 의 `OFFLINE_FESTS` 에 slug 만 더하면 켜진다 |
| iPhone 라인업 이동 | **안내만.** '먼저 홈 화면에 추가하고 아이콘으로 열어서 담아 주세요'를 시트에 크게 보여 준다 |

> 위 3장의 팩 용량(2.5MB/6.1MB)은 사진을 저장하던 때의 계산이다. 사진을 저장하지 않기로 해서 실제 저장량은 **앱 화면 약 0.7MB(gzip 0.2MB) + 글꼴 약 0.6MB(한국어, 쓰는 글자를 덮는 조각만)** 이다.

## 만든 것 (구조)

| 부분 | 파일 | 하는 일 |
|---|---|---|
| 앱 아이콘 | `scripts/make-icons.mjs` → `public/icons/` | 휴대폰 모양 아이콘 192·512·maskable·apple-touch(180)를 SVG 로 그려서 PNG 로 |
| 설치 정보 | `index.html` · `public/manifest.webmanifest` · `scripts/route-html.mjs` | 홈 화면에 추가용 태그. 페스티벌 페이지마다 `/manifest/<slug>.webmanifest` 를 따로 만들어서 아이콘으로 열면 그 페스티벌 주소로 열린다 |
| 서비스워커 | `scripts/sw.template.js` + `scripts/make-sw.mjs` → `dist/sw.js` | 빌드 때 파일 목록·번호를 채워 만든다. 앱 화면 저장, 어떤 주소로 열어도 `/index.html` 로 대신 열기, 글꼴 캐시 제공. API·분석·드랍/클립 목록은 건드리지 않는다 |
| 저장·삭제 | `src/offline.ts` | 서비스워커 등록, 지금 언어의 글꼴 조각을 Cache API 에 직접 저장(이미 화면에 떠 있던 글꼴도 빠짐없이), 삭제, 연결 상태 |
| 화면 | `src/fest/OfflineSheet.tsx` · `src/components/OfflineBadge.tsx` | 카드 모양 줄의 '오프라인으로 쓰기' 칩과 안내 시트(① 홈 화면에 추가 ② 저장), 오프라인일 때 위쪽 배지(이름만 보인다 · 시간표 기준 시각) |
| 오프라인 동작 | `src/config.ts` · `src/blobHealth.ts` · `src/i18n.tsx` · `src/styles.css` | 오프라인이면 `faceSrc` 가 null → 이름만. 사진 저장소 경보는 끔. 연결 상태가 바뀌면 화면이 다시 그려짐. 포스터·랭킹·홈 썸네일은 숨김 |

### 되돌리기 (문제가 생겼을 때)
1. `scripts/sw.template.js` 맨 아래 `KILL` 주석 안의 코드로 파일 전체를 바꿔서 배포한다 (스스로 등록을 해제하고 `fl-` 캐시를 지우고 화면을 새로고침한다). 브라우저가 `/sw.js` 를 열 때마다 새로 확인하므로 사용자가 사이트를 열면 사라진다.
2. 그다음 `src/offline.ts` 의 `OFFLINE_FESTS` 를 비워 칩을 숨긴다.
