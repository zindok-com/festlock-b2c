# 나만의 컬렉션(페스티벌 팔찌) — 앱 UI·UX·기능 명세

작성 2026-11-19 · 웹(festlock.vercel.app)에서 만든 "나만의 컬렉션"을 **앱에 그대로 옮길 수 있게** 기능·디자인·레이아웃·규칙을 정리한 문서입니다.
**빠진 것:** "2026년, 내가 간 페스티벌 자랑하기"(연말 공유 버튼)는 이 문서에서 다루지 않습니다.

- 웹 구현 위치: `src/band/` (화면) · `src/band/three/engine.ts` (3D, `scripts/make-band-engine.mjs` 가 시안에서 만들어 냄) · `api/band.ts` (서버)
- 시안(원본 디자인·움직임): `docs/band-collection/sample.html`, `sample-source.html`
- 처음 기획: `docs/팔찌-컬렉션-구현-프롬프트.md`
- 화면 캡처: `docs/band-collection/shots/` (아래 본문에 파일 이름을 적어 둠)

## 1. 한눈에 보기

| 용어 | 뜻 |
|---|---|
| **팔찌 (band)** | 페스티벌 입장 팔찌 한 개. 3D 진열에 한 줄(리본)로 걸린다 |
| **티켓 키 (key)** | `페스티벌slug:연도:등급:날짜` 예) `nol-festival:2026:ga:day1`. 같은 키 = 같은 팔찌 종류 |
| **디자인 (design)** | 그 티켓 키의 팔찌 그림. **처음 등록한 사람의 그림이 모두의 그림**이 된다 |
| **수집가 (collector)** | 팔찌를 모으는 사람. 이름 + 인스타그램만 있음 (계정 없음) |
| **내 컬렉션** | 내가 담은 팔찌들 (최대 60개) |
| **관리 코드** | 낱말 4개짜리 코드. 다른 기기에서 내 컬렉션을 찾거나 고칠 때 씀. 처음 한 번만 보여 줌 |

사용자 흐름 (한 줄 요약)
1. 컬렉션 화면을 연다 → 내 팔찌가 있으면 **내 컬렉션**, 없으면 **최근 올라온 다른 사람 컬렉션**이 3D 로 보인다.
2. **＋ 추가** → 팔찌 만들기(스캔) 화면 → 티켓 정보 + 사진 → **리본으로 걸기**
3. 처음이면 **프로필(이름·인스타·공개 동의)** → **관리 코드** 안내 → 화면이 내 컬렉션으로 바뀐다.
4. **공유** → 9:16 인스타 스토리 이미지 저장 / 스토리로 보내기 / 링크 복사 (`/c/{id}`)
5. **구경하기** → 다른 사람 컬렉션 목록 → 한 사람의 컬렉션 3D 로 보기 · 인스타그램 · 신고

## 2. 화면 구성 · 이동

| 웹 주소 | 앱 화면 (권장 이름) | 내용 |
|---|---|---|
| `/collection` | 컬렉션 (메인) | 전체 화면 3D. 내 컬렉션 또는 최근 컬렉션 |
| `/collection/browse` | 구경하기 | 다른 사람 컬렉션 목록 (카드) |
| `/c/{id}` | 수집가 컬렉션 | 한 사람의 컬렉션 전체 화면 3D |
| (모달) | 팔찌 만들기(스캔) | 전체 화면 시트. 컬렉션 화면 위에 열림 |
| (모달) | 프로필 만들기 · 관리 코드 · 공유 · 신고 | 가운데 카드형 창 |

이동
- 홈 → (로고 아래 "나만의 컬렉션을 만들자" 버튼) → 컬렉션
- 컬렉션 **오른쪽 위 "구경하기"** → 구경하기 → 카드 → 수집가 컬렉션
- 구경하기 위쪽 **"← 내 컬렉션"** → 컬렉션
- 수집가 컬렉션 **오른쪽 위 "구경하기"** → 구경하기
- 컬렉션 **왼쪽 위 FestLock 로고** → 홈
- 뒤로 가기(안드로이드)·스와이프: 열린 시트/창을 먼저 닫고, 그다음 화면 이동

배경 빛 번짐 (컬렉션 화면): 세 개의 큰 원형 그라데이션
- 왼쪽 위 보라 `rgba(123,75,255,.5)` (8%, 6% 위치, 55%×38%)
- 오른쪽 가운데 분홍 `rgba(255,79,160,.32)` (100%, 48%)
- 왼쪽 아래 보라 `rgba(91,59,208,.45)` (0%, 96%)
- 그 위에 아주 옅은 노이즈(필름 결) 20% 오버레이

### 글꼴
- 한글·본문: **Pretendard** (없으면 Noto Sans KR)
- 로고·영문 강조: **Rubik** 800

- 3D 팔찌 그림 안 글자: Montserrat 900 / Pretendard / 모노 (시안 그대로)

### 모양
- 둥근 알약 버튼: 높이 44px(상단) · 반지름 999px · 반투명 `rgba(11,6,32,.45~.5)` + 배경 흐림(blur 8px) + 테두리 `rgba(246,241,255,.2)`
- 누를 때: 0.93~0.95배로 줄었다 돌아옴
- 움직임 줄이기(접근성 설정)가 켜져 있으면: 깜빡임·흔들림·자동 회전을 끈다

## 4. 컬렉션 화면 (전체 화면 3D) — 레이아웃 (2026-11-20 새 배치)

캡처: `shots/layout-v3.webp`(수집가 5개), `shots/layout-v3-hub.webp`(컬렉션 화면, 연말 자랑하기 버튼 포함)

```
┌──────────────────────────────────────────────┐  ← 안전 영역(노치) 아래부터
│ (‹)          내 컬렉션            👥 구경하기 │  위 줄 (위 14px, 좌우 14px)
│              팔찌 3개                   (🚩) │  가운데 제목 2줄 · 신고는 구경하기 아래(수집가 화면)
│            ‹  🎀 걸기 1/4  ›                 │  진열 바꾸기 (위 76px)
│ (+)                                  [전체]  │  왼쪽 확대 버튼 · 오른쪽 연도 목록 (위 168px)
│ (−)        3D 진열 영역              2026    │  3D 영역: 위 124px ~ 독 위, 좌우 86px 비움
│ (⛶)                                  2025    │
│ (⟲)                                          │
│                                              │
│        ( SAMPLE FEST 2026 · GA · Day 1 )     │  팔찌를 누르면 흰 말풍선 (독 바로 위)
│          ┌──────────┬──────────┐             │
│          │  ⇪ 공유  │  ⊕ 추가  │             │  아래 독 (아래 18px)
│          └──────────┴──────────┘             │
└──────────────────────────────────────────────┘
```

- **웹은 휴대폰 화면 기준.** PC 등 넓은 화면에서는 가운데에 폭 480px 로 보여 주고 바깥은 더 어두운 바탕 `#05030f`

### 4-1. 위 줄 (3칸: 왼쪽 · 가운데 · 오른쪽, 왼쪽·오른쪽 칸 폭이 같아 제목이 정가운데)
| 자리 | 컬렉션 화면 | 수집가 컬렉션 화면 |
|---|---|---|
| 왼쪽 | **‹ 동그라미 버튼** (44px, 테두리 `rgba(246,241,255,.3)`, 바탕 `rgba(246,241,255,.08)`) → 홈 | 같음 |
| 가운데 | 제목 **내 컬렉션** (800 18px) + 아래 `팔찌 n개` (700 13px 흐린 글자). 내 팔찌가 없을 때는 `○○님의 컬렉션 보기 ›` 링크 | 그 사람 이름 + `팔찌 n개` |
| 오른쪽 | **👥 구경하기** — 테두리 없이 아이콘 + 글자(800) | 구경하기 + 그 아래 🚩 신고(44px 원) |

- 연도를 고르면 `팔찌 n개` = 그해 팔찌 수
- 좁은 휴대폰(370px 이하): 제목 16px

### 4-2. 진열 바꾸기 (제목 아래 한 줄)
- `‹  🎀 걸기  1/4  ›` — 화살표(44px, 흰 글자 28px) · 이름(800 16px) · 순번(800 13px)
- 4종: 🎀 걸기 · ⭕ 손목 · 🎠 모빌 · 🖼 액자. 고른 진열은 기기에 저장(다음에 열어도 유지)
- 화면 읽기용으로 숨은 탭 4개도 같이 둔다 (접근성)

### 4-3. 오른쪽 연도 목록 (세로)
- **전체 · 2026 · 2025 …** (팔찌가 있는 해만, 최근 해부터). 칸: 폭 72px 이상 · 높이 48px · 반지름 12px · 700 16px 흐린 글자
- 고른 칸: 밝은 바탕 `rgba(246,241,255,.12)` + 흰 글자 800
- 고르면 그해 팔찌만 3D 로 **새로 걸린다** (떨어지는 애니메이션 다시)
- 팔찌가 0개면 목록을 숨김. 고른 해의 팔찌가 사라지면 자동으로 "전체"
- 다른 해를 보고 있을 때 새 팔찌를 걸면, 새 팔찌가 보이도록 "전체"로 돌아간다
- 공유 이미지에도 고른 해가 반영된다 (8장)

### 4-4. 왼쪽 조작 버튼 (세로 4개, 48px 원, 테두리 + 반투명, 간격 12px)
| 버튼 | 동작 |
|---|---|
| 🔍+ 확대 | 카메라를 가까이 |
| 🔍− 축소 | 멀리 |
| ⛶ 맞춤 (네 모서리 아이콘) | 팔찌 전체가 화면에 맞게 |
| ⟲ 다시 보기 (돌아가는 화살표) | 팔찌가 떨어지는 등장 애니메이션 다시 |

- 3D 영역은 이 버튼 열과 오른쪽 연도 목록 **사이에만** 그린다 (좌우 86px 씩 비움, 연도 목록이 없으면 66px) → 팔찌가 버튼 뒤에 겹치지 않음
- 세로 화면에서 🎀 걸기는 **한 줄 6개** (가로 화면 10개)

### 4-5. 아래 독 (공유 · 추가)
- 반투명 사각형 하나에 두 칸: 반지름 14px · 바탕 `rgba(246,241,255,.14)` · 테두리 `rgba(246,241,255,.26)` · 그림자 `0 10px 30px rgba(0,0,0,.3)`
- 칸: 폭 112px 이상 · 높이 68px · **아이콘 위, 글자(700 13px) 아래** · 두 칸 사이 세로 구분선(위아래 끝까지)
- 주 동작 칸(＋ 추가 / 수집가 화면의 인스타그램)은 아이콘을 **분홍 원(36px, `#FF4FA0`)** 안에 흰색으로
- 공유 칸은 선 아이콘만. 보여 줄 팔찌가 없으면 흐리게(40%) 비활성
- 수집가 컬렉션 화면: **공유 · 인스타그램**(그 사람이 인스타를 적었을 때만)
- 팔찌를 누르면 독 바로 위에 흰 알약 말풍선 `페스티벌 2026 · GA · Day 1` (2.6초)

### 4-6. 상태별 화면
| 상태 | 3D 영역 가운데 문구 | 그 밖 |
|---|---|---|
| 불러오는 중 | "불러오는 중이에요" | 버튼은 보임 |
| 내 컬렉션이 비어 있음 | "아직 걸린 팔찌가 없어요. ＋ 추가로 첫 팔찌를 걸어 보세요!" | 공유는 비활성 |
| 아무 컬렉션도 없음 | "아직 올린 사람이 없어요. 첫 번째가 되어 보세요!" | |
| 수집가 컬렉션이 비어 있음 | "아직 담은 팔찌가 없어요" | |
| 오류 | "목록을 불러오지 못했어요" + **다시 시도** 버튼(캡션 자리) | |
| 오프라인 | "인터넷이 연결되면 볼 수 있어요" | 연결되면 자동으로 다시 불러옴 |
| 3D 를 못 그리는 기기(WebGL 없음) | "이 기기에서는 3D를 볼 수 없어서 사진으로 보여 드려요." | 팔찌를 2D 격자 카드로 보여 줌 (상단·캡션·아래 버튼은 같은 위치) |

### 4-7. 화면에서 팔찌를 눌렀을 때
- 그 팔찌가 펄럭이고, 아래쪽에 말풍선: `페스티벌 2026 · GA · Day 1` (2.6초 뒤 사라짐)
- 엔진 안내(예: "60개까지 걸 수 있어요")도 같은 말풍선으로

## 5. 3D 진열 4종

공통
- **등장:** 팔찌가 위에서 하나씩 떨어져 스프링처럼 자리 잡는다 (팔찌 사이 간격 최대 0.22초, 많을수록 짧게)
- **끌기:** 좌우로 끌면 돌아간다. **걸기·손목·모빌은 360도 제한 없이**, 손을 떼면 관성으로 조금 더 돌다 멈춤
- **두 손가락 벌리기/오므리기:** 확대·축소 (버튼과 같음)
- **카메라:** 진열 크기(가로·세로)에 맞춰 자동으로 거리 조절. 세로 화면(휴대폰)과 가로 화면 모두
- **애니메이션 시간 기준:** 한 장면에 최대 1/30초씩 진행 (느린 기기에서는 느려지지만 끊기지 않음)
- 바람에 흔들리듯 천이 살짝 펄럭임 (움직임 줄이기 설정이면 40%로)

### 5-1. 🎀 걸기 — 코르크 띠 + 압정
캡처: `shots/pin-1-scan.webp`, `shots/pin-mid-scan.webp`, 옆에서 본 모습 `shots/pin-mid-rot.webp`
- 한 줄에 **10개**, 넘치면 아래에 새 줄
- 줄마다 **코르크 띠** (높이 0.3, 두께 0.08, 팔찌 폭에 맞춰 늘어남, 양 끝 여유 0.17). 코르크 결은 갈색 `#b8895b` 바탕에 어두운·밝은 점을 흩뿌린 그림을 반복
  - 예전의 분홍 양쪽 공·분홍 줄은 **없앰** (대표 요청)
- 팔찌 윗부분이 띠 앞에 오고, **압정이 팔찌를 뚫고 띠에 꽂힌** 모양
  - 압정 모양: 머리(원판) · 손잡이 · 받침 · 은색 바늘. 살짝 기울어져 있음(개수마다 조금씩 다르게)
  - **압정 색 = 팔찌 윗부분 색과 가장 다른 색** (검정 · 흰색 · 빨강 · 파랑 · 초록 · 노랑 중에서 고름, 검정·흰색을 조금 더 우선). 팔찌와 압정 색이 비슷해 묻히지 않게 (대표 요청)
  - 팔찌가 내려와 멈추면 압정이 **앞에서 날아와 꽂힘**, 팔찌가 빠질 때는 압정이 먼저 빠짐
- 팔찌 길이: 사진 비율에 따라 2.0~4.2, 폭 0.3~0.62 (디자인 팔찌는 2.7 × 0.34 + 위쪽 태그)
- 띠 윗선 위로는 팔찌가 보이지 않음 (아래로 펼쳐지며 등장)

### 5-2. ⭕ 손목
- 기둥에 팔찌 고리(원형)를 차곡차곡 끼움. **기둥 하나에 14개**, 넘으면 기둥 추가
- 360도 회전

### 5-3. 🎠 모빌
캡처: 1개 `shots/mob-1.webp`, 60개 `shots/mob-big.webp`
- 금색 고리에 팔찌가 빙 둘러 매달려 천천히 돎 (움직임 줄이기면 멈춤)
- **한 층 15개**, 넘으면 아래로 층이 생김 (층 간격 2.7)
- **고리 크기 = 그 층 팔찌 수에 맞춤** (대표 요청: 1개일 때 빈 공간이 너무 많았음)
  - 반지름 = 팔찌 수 × 0.62 ÷ 2π, **최소 0.42 · 최대 1.55**
  - 팔찌를 더하면 고리가 부드럽게 커지고, 팔찌들은 고리를 따라 같은 간격으로 다시 벌어짐
  - 카메라도 가장 큰 고리에 맞춰 당겨짐 (1개면 가까이)
- 고리 위 가운데 구슬에서 네 가닥 줄로 고리를 매달고, 위층(또는 천장)으로 줄이 이어짐

## 11. 데이터 · 서버 규칙 (`api/band.ts`)

| 요청 | 하는 일 |
|---|---|
| GET `?a=design&key=` | 그 티켓 키의 첫 디자인 (없으면 404) |
| GET `?a=collectors&fest=&sort=recent\|most&cursor=` | 구경하기 목록 |
| GET `?a=collector&id=` | 한 사람의 이름·인스타·팔찌들 |
| POST `?a=profile` | 프로필 만들기 → { id, code } / 고치기 |
| POST `?a=recover` | 관리 코드로 내 프로필 찾기 (틀리면 10분에 8번까지) |
| POST `?a=design` | 디자인 올리기 (첫 등록자 것이 모두의 것, 30초 잠금으로 동시 등록 방지) |
| POST `?a=collect` / `uncollect` | 있는 디자인을 내 컬렉션에 담기 / 빼기 |
| POST `?a=delete-profile` | 프로필과 내 기록 지우기 (디자인은 남음) |
| POST `?a=report` | 신고 |

- 한 사람 최대 **60개**, 이름 **20자**
- 이미지: WebP 또는 JPEG, **300KB 이하**, 가로·세로 **64~1024px**, 저장 위치 `bands/{key}.webp|jpg` (공개, 1년 캐시)
- 원본 사진은 올리지 않음 (펴고·가리고·다듬은 띠 그림만)
- 남용 방어: 같은 사이트에서 온 요청만 쓰기 허용 → 횟수 제한(디자인 10분 3개·하루 20개, 새 프로필 시간당 5개, 담기 분당 60번 등) → 값 검사
- 데이터 모양
  - 디자인 `{ key, fest, year, grade, day, style, pal(색 목록), img, w, h, by, at, status }`
  - 수집가 `{ name, ig, ownerHash, codeHash, at, hidden }`
  - 내 팔찌 목록: 담은 시각 순

## 12. 접근성 · 성능 · 오프라인

- 모든 버튼에 이름(aria-label). 3D 는 화면 읽기 프로그램이 읽을 수 없으므로 **숨은 팔찌 목록**을 같이 둠 ("페스티벌 2026 GA Day 1 팔찌")
- 키보드 포커스 테두리 흰색 2px
- 움직임 줄이기: 깜빡임·흔들림·자동 회전 끔
- 3D 엔진(three.js)은 컬렉션 화면에 들어갈 때만 불러옴. 팔찌 그림은 공용 저장소(CDN)에서
- 3D 가 안 되는 기기: 2D 격자로 자동 전환
- 오프라인: 문구 표시 후 연결되면 다시 불러옴
