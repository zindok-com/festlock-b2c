## 00. 전체 화면 컬렉션 + 구경하기 별도 페이지 (대표 요청: 참고 화면처럼)

| 주소 | 화면 |
|---|---|
| `/collection` | **화면 전체를 채우는 3D 컬렉션**. 왼쪽 위 **구경하기**(다른 사람들의 컬렉션 목록으로) · 가운데 위 **‹ 🎀 걸기 1/4 ›**(진열 4종 바꾸기) · 오른쪽 위 FestLock → 홈 · 왼쪽 아래 확대/축소/전체/다시 · 아래 가운데 **공유 · ＋ 추가** |
| `/collection/browse` | **구경하기 목록**(정렬·페스티벌 거르기·카드·더 보기) — 예전 허브의 목록을 이 별도 페이지로 옮김. 위에 "← 내 컬렉션" |

- 팔찌 등록(3단계)이 열리기 전까지 "내 컬렉션"이 비어 있어서, `/collection` 은 **최근 올라온 사람의 컬렉션**을 보여 주고 "○○님의 컬렉션 보기 ›"로 그 사람 페이지에 이어 줘요. 등록이 열리면 내 팔찌로 바뀌어요.
- 3D 는 위 버튼 줄과 아래 버튼 사이에 맞춰 보이고(진열이 버튼에 가리지 않게), 배경은 화면 전체예요. 전체 화면에서는 페이지 스크롤이 없어서 시안처럼 모든 손동작(끌기·두 손가락 확대·휠)이 3D 로 가요.
- **공유**: 휴대폰 공유 창, 안 되면 링크 복사 + "링크를 복사했어요".
- 좁은 화면(400px 이하)에서는 오른쪽 위 FestLock 글자를 숨기고 아이콘만.
- 새 문구 10개 × 9개 언어. 스크린샷: `full-collection*.png`, `full-collector*.png`, `full-add-sheet.png`, `browse.png`.

## 0. 오전에 바꾼 것 — 3D 진열 (대표 요청: "위 html처럼 3D로")

새벽 자동 실행은 3D 지시가 반영되기 전 내용(2D 격자)으로 돌았어요. 오전에 **시안(`docs/band-collection/sample.html`)과 같은 3D 진열**로 바꿨어요.

**보는 곳**: http://localhost:5201/collection → 카드 → 컬렉터 페이지 (60개 꽉 찬 예시: http://localhost:5201/c/cdemo00011)

| 화면 | 3D |
|---|---|
| 컬렉터 페이지 `/c/{id}` | 탭 4개 **🎀 걸기 · ⭕ 손목 · 🎠 모빌 · 🖼 액자** (고른 탭 기억) + 어두운 3D 무대 + 확대/축소/전체 보기 + 많을 때 이전/다음 + ↻ 다시(등장 모션) + 팔찌를 누르면 "페스티벌 연도 · 등급 · 날짜" 말풍선 |
| 허브 `/collection` | 소개 아래 **"최근 올라온 컬렉션"** 3D 미리보기(🎀 걸기) + "○○님의 컬렉션 보러 가기" |

**시안과 같게 지킨 것** (시안 코드를 그대로 옮겼어요)
- 진열 4종 모두 위에서 아래로 내려오는 등장 모션 · 손목·모빌은 좌우로 끌면 360도 돌고 놓으면 관성(감속 2.2/초, 최대 8rad/초) · 걸기·액자는 놓으면 정면으로 돌아옴 · 모빌 자동 회전 · 액자는 한 줄 3개 → 2개 벽돌 배열, 3개 줄 양 끝은 액자 안쪽에서 잘림 · 두 손가락 확대 · 모션 줄이기 설정 존중
- 걸기는 한 줄 10개(60개면 레일 6줄), 손목은 기둥 하나에 14개(60개면 기둥 5개)

**어떻게 옮겼나**
- `scripts/make-band-engine.mjs` 가 시안의 3D 코드를 줄 범위로 잘라 `src/band/three/engine.ts` 를 **자동으로 만들어요**(손으로 고치지 말고 스크립트를 고쳐서 다시 만들기). 스캔·AI·시안 버튼 연결은 빼고, 앱 연결부는 `scripts/band-engine-control.js`.
- 팔찌 데이터 → 시안 모양: **사진 그대로**(style photo)는 올린 띠 이미지를 리본 텍스처로, **팔찌로 디자인**(style design)은 색(pal)으로 시안의 **금사 무늬**를 그려요. 사진을 못 불러오면 금사 무늬로 대신해요.
- React 부품 `src/band/BandStage.tsx`. 3D 코드(three 포함)는 **컬렉션 화면에서만 따로 받아요**.

**시안과 다르게 한 것 (이유 있음)**
1. 🖼 액자 뒤판을 조금 뒤로 밀었어요(z -0.04 → -0.12). 뒤판과 팔찌가 너무 가까워 깊이 정밀도가 낮은 그래픽(소프트웨어 렌더링·일부 폰)에서 **검은 얼룩**이 생겼어요. 보이는 모양은 같아요.
2. 페이지 안에 들어가므로 **확대 전에는 위아래로 밀면 페이지가 스크롤**돼요(시안은 무대가 화면 전체라 스크롤이 없음). 좌우 끌기·확대 후 이동은 시안과 같아요. 마우스 휠도 확대 전 아래로 굴리면 페이지가 내려가요.
3. 남의 컬렉션이라 시안의 "+ 추가 / − 빼기 / 빠르게 채우기" 버튼은 없어요(등록은 3단계).
4. 시안 안내 문구 대신 9개 언어 한 줄 "좌우로 끌어서 돌려 보세요. 팔찌를 누르면 이름이 나와요."(새 문구 16개 × 9개 언어).
5. WebGL 을 못 쓰는 기기에서는 사진 격자 + "이 기기에서는 3D를 볼 수 없어서 사진으로 보여 드려요."

**용량**: 메인 JS 644,640 B → 644,652 B (+12 B, 사실상 그대로). 3D 조각 `engine-*.js` 521 KB(gzip 137 KB)와 `BandStage-*.js` 38 KB 는 컬렉션 화면을 열 때만 받아요(QA 가 홈에서 안 받는 것을 확인).

**추가한 패키지**: `three@0.169.0`(시안과 같은 r169), `@types/three@0.169.0`(개발용). 설치하면서 QA 용 playwright 가 지워져서 `playwright@1.65.0` 을 저장 없이 되살렸어요.

**스크린샷** (`docs/band-collection/screens/`): `3d-12-{scan,wrist,mobile,frame}.png`(12개), `3d-60-{scan,wrist,mobile,frame}.png`(60개), `3d-hub.png`, `3d-collector-dark.png`, 비교용 시안 `sample-{scan,wrist,mobile,frame}.png`.

**검증**: (아래 4장 표에 숫자)
- 테스트 브라우저는 그래픽 카드 없이 소프트웨어로 그려서 **초당 3장** 정도라, 화면에서는 애니메이션이 실제보다 약 10배 느리게 보여요(시안 코드가 한 장당 시간을 1/30초로 묶음). 실제 폰 속도는 [확인 못 함] — **휴대폰에서 직접 열어 보는 확인이 필요해요**(특히 60개 진열의 부드러움·발열).

## 2. 만든 것 (화면별)

### 홈 (`/`)
- 로고(`.home-logo`) 바로 아래, 제목 위에 큰 버튼: **"나만의 컬렉션을 만들자"** + 작은 설명 "다녀온 페스티벌 팔찌를 기록하고 구경해요". 높이 60px, 핑크→보라 그라데이션(기존 `btn main`과 같은 색), 라이트/다크 모두 OK.

### 컬렉션 허브 (`/collection`)
- 홈과 같은 상단(FestLock 로고·언어 메뉴), 제목 "나만의 페스티벌 팔찌 컬렉션", 한 줄 소개.
- **"＋ 내 팔찌 추가하기"** → 안내 창 "팔찌 등록은 곧 열려요" + **@festlock 팔로우하기**(새 탭, `noopener noreferrer`) + 닫기. ✕·바깥 누르기·뒤로가기로도 닫혀요.
- **구경하기**: 정렬 [최근 등록순 | 많이 다닌 순], 페스티벌 칩([전체] + festivals.json 8곳). 페스티벌을 고르면 정렬은 최근순으로 고정되고 "많이 다닌 순"은 흐려져요(안내 한 줄).
- 카드: 이름 · "팔찌 N개" · 대표 팔찌 띠 3개(가로 띠, `object-fit:cover`) · → . 누르면 `/c/{id}`.
- 24명씩, 다음 쪽이 있으면 **"더 보기"**.
- 상태: 불러오는 중(뼈대 모양), 비었음("아직 올린 사람이 없어요. 첫 번째가 되어 보세요!"), 오류("목록을 불러오지 못했어요" + 다시 시도), 오프라인("인터넷이 연결되면 볼 수 있어요" → 연결되면 저절로 다시 불러옴).
- 고른 정렬·페스티벌은 주소(`?fest=`, `?sort=most`)에 남아서, 컬렉터 페이지에서 뒤로 와도 같은 목록이 보여요.

### 컬렉터 페이지 (`/c/{id}`)
- "← 구경하기" 링크, 이름, "팔찌 N개", **"인스타그램 구경 가기"** 버튼(새 탭, `noopener noreferrer`).
- ~~"3D 진열은 곧 열려요" + 2열 격자~~ → **오전에 3D 진열로 바꿈(0장)**. 화면 읽기 프로그램용으로 "페스티벌 이름 연도 등급 날짜 팔찌" 목록을 숨겨서 함께 둬요(예: "ZONNAFE 2026 GA Day 1 팔찌"). 2열 격자는 WebGL 이 없을 때만 나와요.
- 아래 작게 **"이 기록 신고하기"** → 이유 고르기(사칭 · 부적절한 사진 · 번호·QR이 보임 · 기타) → `POST /api/band?a=report {type:"collector", target, device, reason}`. 이유를 골라야 보내기가 켜져요. 결과 안내: 접수 / 이미 신고함 / 너무 자주 / 실패.
- 없는 id(또는 형식이 틀린 주소) → "없는 기록이에요" + 구경하기로 돌아가기.

### 새 QA `band` 영역 (34건) 이 확인하는 것
- 문구 사전: 9개 언어 모두 한국어와 같은 키(빠진 문구 없음)
- 홈: 버튼이 로고 바로 아래·제목 위, 44px 이상, `/collection` 으로 이동, 홈에서 컬렉션 파일을 미리 받지 않음
- 허브: 제목·DEMO 배지·카드 8개 이상, 카드 모양, 많이 다닌 순 정렬, 페스티벌 거르기(정렬 고정·주소 반영), 거른 사람의 페이지에 그 페스티벌 팔찌가 있음, [전체] 되돌리기
- 안내 창: 문구·인스타 링크 href/target/rel, 닫기·✕·뒤로가기
- 카드 → `/c/{id}` 이동(이름·팔찌 수 일치), 인스타 버튼 href·target·rel, 2열·alt·3D 안내·뒤로 링크, 신고 흐름, 없는 기록 2가지

- 9개 언어 × (홈 버튼·허브·안내 창·컬렉터·신고 창·없는 기록): 문구 키 이름이 그대로 보이지 않음, 다른 언어에 한국어가 섞이지 않음
- 콘솔 오류 없음

## 5. 예시 데이터가 운영 사이트에 나오지 않는 근거

1. 예시 데이터는 `src/band/api.ts` 에서 **`LOCAL` 이 참일 때만** 불러요. `LOCAL` = 주소의 호스트 이름이 `localhost`·`127.0.0.1`·`[::1]` 인지 (`festStats.ts` 의 DEMO 와 같은 기준). festlock.com 이나 *.vercel.app 에서는 항상 거짓이에요.
2. 그리고 **서버가 실패했을 때만**(연결 실패·JSON 이 아닌 응답·500번대) 바꿔요. 404(없는 사람)나 400 은 예시 데이터로 바꾸지 않아요.
3. 예시 데이터 파일(`demo.ts`)은 **따로 묶인 파일**이고 위 조건일 때만 `import()` 로 받아요. 운영에서는 받지도 않아요.
4. 예시 데이터일 때는 신고를 서버로 보내지 않아요.
5. 예시 데이터의 인스타 링크는 실제 사람 계정과 겹치지 않도록 모두 `@festlock` 이에요.

## 6. 정한 것 (추천안대로 결정한 부분)

- **문구 나누기**: 홈 버튼·탭 제목 6개 키만 메인 사전(`src/band/coreStrings.ts`), 나머지는 컬렉션 화면을 열 때 더해요. 이를 위해 `src/i18n.tsx` 에 `addDict()` 함수 하나를 추가했어요.
- **홈 버튼에 작은 설명 한 줄**("다녀온 페스티벌 팔찌를 기록하고 구경해요")을 더했어요. 빼려면 `Home.tsx` 의 `<span>` 한 줄만 지우면 돼요.
- **기기 id**: `festStats.ts` 의 `deviceId()` 를 `export` 만 해서 그대로 써요(같은 저장 키 `edc26:did`).
- **신고 이유 값**: `impersonation | photo | number | other` 로 서버에 보내요(서버는 80자까지 저장).
- **허브 카드 썸네일**: 서버가 이미지 주소만 주기 때문에 카드 썸네일 alt 는 비우고, 카드 링크에 "OO님의 컬렉션 보기 · 팔찌 N개" 이름을 붙였어요.
- **페스티벌 이름 표시**: festivals.json 이름 끝의 연도는 빼고 연도를 따로 붙여요("ZONNAFE · 2026"). 목록에 없는 페스티벌은 주소 이름을 보기 좋게 바꿔 보여요.
- **바닥 안내**: "비공식 팬메이드… 내 기록이 허락 없이 올라왔다면 인스타그램 @festlock DM" 을 두 화면 아래에 넣었어요(README 의 삭제 요청 방식과 같게).
- **탭 제목**: 컬렉터 페이지는 사람 이름 대신 "팔찌 컬렉션 · FestLock" 고정이에요(언어 바꿀 때 제목이 덮어써지는 문제를 피하려고).
- QA 에서 로컬 미리보기의 `/api/band` 404 는 "정상(예시 데이터로 바뀜)"으로 보고 콘솔 오류에서 뺐어요.
- 화면 확인용 스크립트 `scripts/band-shots.mjs` 를 새로 만들었어요.
