# FestLock 기능 안내 (관객 기준)

> 기준일 2026-11-16. 관객이 화면에서 직접 쓰는 기능만 정리했습니다. 개발·운영(라인업 입력, 사진 업로드, 배포)은 `README.md`, `docs/ADD-FESTIVAL.md` 를 보세요.
>
> **이 문서의 쓰임**: FestLock **UI/UX 가이드라인**을 만들 때 쓰는 입력 자료입니다. 1~6장은 *지금 있는 기능*, **7장은 앞으로 만들 기능(크루 커뮤니티·앱 오프라인 라인업)의 기획**, 8장은 운영 반영 상태, **9장은 디자인 판단에 필요한 현재 화면의 사실**(색·글꼴·상호작용·상태·제약)입니다.

## 1. 한 줄 소개

**페스티벌 타임테이블에서 보고 싶은 아티스트만 골라, 인스타 스토리·폰 잠금화면용 이미지로 저장하는 서비스.**
로그인·설치 없이 링크만 열면 쓸 수 있고, 한국어를 포함해 9개 언어로 보입니다. 주최측과 무관한 비공식 팬메이드 서비스입니다.

## 2. 관객이 할 수 있는 일 (요약)

| # | 할 수 있는 일 | 한마디로 |
|---|---|---|
| 1 | 페스티벌 고르기 | 홈에서 포스터·D-day·날짜·장소를 보고 들어가요 |
| 2 | 타임테이블 보기 | 날짜·무대별로 한눈에, 지금 공연 중인 칸은 표시돼요 |
| 3 | 보고 싶은 공연 담기 | 칸을 탭하면 색이 켜지고 내 라인업에 담겨요 |
| 4 | 아티스트 알아보기 | 꾹 누르면 사진·장르·듣기 링크·드랍/영상을 봐요 |
| 5 | 겹치는 공연 확인 | 담은 공연끼리 시간이 겹치면 알려 줘요 |
| 6 | 배경화면 만들기 | 담은 라인업을 스토리(9:16)·폰 배경화면(9:19) 이미지로 저장·공유해요 |
| 7 | 카드 모양 바꾸기 | 시간표와 이미지의 디자인을 8가지 중에서 골라요 |
| 8 | 인기 아티스트 보기 | 다른 관객이 많이 고른 아티스트 랭킹을 봐요 |
| 9 | 오프라인으로 쓰기 | 인터넷이 없어도 시간표 보기·담기·이미지 만들기가 돼요 (TML 한정) |
| 10 | 내 언어로 보기 | 한·영·일·중(간체/번체)·스페인·베트남·태국·인도네시아어 |

## 3. 관객 이용 흐름

```
링크 열기 → (처음이면) 사용법 안내 → 날짜 고르기 → 보고 싶은 공연 탭
   → (궁금하면) 꾹 눌러 아티스트 정보·듣기 → 겹침 확인
   → 배경화면 만들기 → 모양·옵션 고르기 → 이미지 저장 / 스토리 공유
```

선택한 라인업은 **내 폰(브라우저)에 저장**돼서 다시 열어도 남아 있습니다. 다른 기기와 자동으로 맞춰지지는 않습니다.

## 4. 기능 상세

### 4.1 홈 · 페스티벌 목록
- 포스터 썸네일과 함께 페스티벌 이름·날짜·장소가 카드로 나옵니다. 썸네일을 누르면 포스터를 크게 볼 수 있습니다(여러 장이면 넘겨 봄).
- 상태 배지: **D-n**(남은 날), **진행 중**, **종료 · 다시 보기**, **준비 중**. 끝난 페스티벌도 타임테이블 보기·배경화면 만들기는 계속 쓸 수 있습니다.
- 라인업이 아직 없으면 "타임테이블 준비 중" 안내 페이지가 열립니다.
- 맨 아래에서 `@festlock` 인스타그램 팔로우로 이어집니다.

### 4.2 타임테이블 보기
- **날짜 탭**: 날짜별로 바꿔 봅니다. 탭에 그날 **담은 팀 수**가 숫자로 붙습니다.
- **무대별 열**: 무대가 많으면 옆으로 밀어서 보고, 2~3곳이면 한 화면에 다 보입니다. 무대마다 색이 다릅니다.
- **시간 눈금**: 왼쪽에 시간이 나오고, 자정이 지난 공연은 00:00부터 이어서 적습니다. 해외 페스티벌은 **현지 시각 기준**임을 화면에 알려 줍니다.
- **지금 공연 중** 표시: 진행 중인 칸에 불빛 표시가 붙습니다(페스티벌 기간 중).
- **거꾸로 보기**(새 화면 4곳): 헤드라이너(늦은 시간)부터 위에서 아래로 보도록 순서를 뒤집습니다. 설정은 기억됩니다.

### 4.3 라인업 담기
- 칸을 **한 번 탭**하면 색이 켜지며 담기고, 다시 탭하면 빠집니다.
- 아래 고정 바에 **"N팀 선택"**과 **초기화**, **배경화면 만들기** 버튼이 있습니다. 초기화는 실수 방지를 위해 한 번 더 눌러야 전체 삭제됩니다.
- 같은 시간대에 두 공연을 담으면 **"⚠ 시간 겹침 N곳"**이 나옵니다. 누르면 어떤 공연끼리 겹치는지 날짜별 목록이 열리고, 한 쌍에서는 하나만 볼 수 있다는 안내가 함께 나옵니다.

### 4.4 아티스트 정보 창 (꾹 누르기)
칸을 **꾹 누르면** 창이 열립니다. 페스티벌에 따라 아래가 들어 있습니다.

| 항목 | 내용 |
|---|---|
| 사진 | 아티스트 사진. 사진이 없으면 이니셜 아이콘 |
| 기본 정보 | 이름, 무대, 시간, 함께 나오는 아티스트(B2B 등) |
| 장르 | 검색으로 확인한 장르. **앞에 `~`가 붙으면 추정값**이라 정확하지 않을 수 있음. 정보가 없으면 "장르 정보 없음" |
| 듣기 | **Spotify · YouTube · Apple Music**(한국 페스티벌은 멜론)으로 이름 검색 연결. 프로필이 없거나 동명이인일 수 있다는 안내 포함 |
| 드랍 미리듣기 | 창이 열리면 YouTube 플레이어가 위쪽에 열려 **드랍 구간을 바로 재생**. 못 틀면 "YouTube에서 보기" 안내 |
| 아티스트 제공 영상 | (ZONNAFE) 아티스트가 보낸 영상이 바로 재생. 소리는 "소리 켜기"를 눌러야 나올 수 있음 |
| 담기/빼기 | 창 안에서도 내 타임테이블에 담고 뺄 수 있음 |

### 4.5 카드 모양 (새 화면 4곳: ZONNAFE · ULTRA TAIWAN · TML · VAC)
"카드 모양" 버튼 → 미리보기를 보며 고르고 **적용**. 선택한 모양은 **시간표 · 아티스트 창 · 저장되는 이미지**에 똑같이 적용됩니다. 나중에 언제든 바꿀 수 있고 기억됩니다.

| 모양 | 느낌 |
|---|---|
| 포스터 카드 | 포스터처럼 사진과 큰 글자 |
| 포토 글라스 *(기본)* | 사진 위에 반투명 이름 띠 |
| 미니멀 | 깔끔한 글자 중심, 무대 색 막대 |
| 듀오톤 블록 | 굵은 색 블록 + 큰 이름. 가능하면 **배경 지운 사진**을 크게 |
| 글라스 잠금화면 | 유리 같은 반투명 카드 |
| 폴라로이드 | 인화 사진 느낌 |
| 터미널 레이브 | 코드 화면 스타일 |
| 모노 포토 | 사진이 카드 전체, 안 고르면 흑백/고르면 컬러 |

- 고른 칸은 모양마다 **색으로 켜짐**을 보여 줍니다(체크 표시는 없음). 글자 테두리는 글자 색이 밝으면 검정, 어두우면 흰색으로 자동으로 맞춰집니다.
- 두 사람이 함께 하는 공연(B2B)은 한 장에 두 사람이 같이 나옵니다(TML 10팀).

### 4.6 배경화면 만들기
"배경화면 만들기"를 누르면 창이 열리고 **미리보기**를 보며 설정합니다.

| 설정 | 선택지 |
|---|---|
| 크기 | **인스타 9:16**(1080×1920) / **폰 배경화면 9:19**(1080×2280) |
| 날짜 | 날짜별 또는 "토+일"처럼 묶어서(페스티벌에 따라) |
| 배치 | 두 날을 한 장에 담을 때 위아래 / 좌우 (EDC KOREA) |
| 보기 방식 | **✨ AI 추천**(고른 공연만 보기 좋게 배치) / **전체 스테이지**(안 고른 공연은 어둡게) |
| 옵션 | **시계 자리 비우기**(잠금화면 시계에 안 가리게) · **상단 텍스트 축소** · **입장 시간부터**(이전 공연 제외) · **DJ 사진 빼기** |
| 카드 모양 | 4.5와 같음(창 안에서 바로 변경) |

저장하는 방법은 세 가지입니다.
1. **이미지 저장** — 바로 내려받기. 저장 직전에 "FestLock, 곧 앱으로 나와요" 안내 팝업이 한 번 뜨고, "이미지 저장하기"를 누르면 저장됩니다.
2. **크게 보기** — 이미지를 크게 띄우고 **꾹 눌러 사진에 저장**.
3. **스토리 공유** — 휴대폰 공유창 → Instagram → 스토리로 바로 올리기.

그 밖에:
- **"이 배경화면 어때요? 👍 👎"**: 결과물에 대한 의견을 남기면 이미지를 더 보기 좋게 만드는 데 쓰입니다(다시 눌러 바꿀 수 있음).
- 창 맨 아래에 "곧 앱으로 나와요 · 인스타그램 팔로우" 안내 카드가 있습니다.
- **인스타·카카오톡 안 브라우저**에서 열었을 때는 저장·공유가 막혀 있어서, "휴대폰 브라우저로 열기" 또는 "크게 보기에서 저장하기" 안내가 나옵니다.

### 4.7 아티스트 랭킹
- "아티스트 랭킹"(EDC KOREA는 "DJ 랭킹") 버튼으로 **다른 관객이 배경화면을 만들 때 많이 고른 아티스트**를 봅니다. 전체 TOP 10, 무대별, 시간대별 순위가 있습니다.
- 한 기기에서 같은 아티스트는 **한 번만** 셉니다. 오프라인에서는 보이지 않습니다.

### 4.8 오프라인으로 쓰기 (TOMORROWLAND THAILAND 한정)
인터넷이 약한 현장·해외를 위한 기능입니다.
1. "오프라인으로 쓰기" → **홈 화면에 추가**(iPhone: Safari 공유 버튼 / Android: 앱 설치).
2. **오프라인 저장** 버튼을 눌러 한 번 저장(앱 화면과 글꼴 합쳐 약 1~1.5MB).
3. 이후 비행기 모드에서도 **시간표 보기, 라인업 담기, 배경화면 이미지 만들기**가 됩니다.

알아둘 점: 오프라인에서는 **DJ 사진 없이 이름만** 나오고, 영상·듣기 버튼·랭킹·포스터는 인터넷이 있을 때만 됩니다. 저장은 사용자가 버튼을 누를 때만 하며 "저장 지우기"로 지울 수 있습니다. iPhone은 Safari와 홈 화면 앱의 저장 공간이 따로라서 **홈 화면 아이콘으로 연 뒤에** 라인업을 담아야 합니다. 인스타·카톡 안 브라우저에서는 설치할 수 없습니다.

### 4.9 언어
- 한국어 · English · 日本語 · 简体中文 · 繁體中文 · Español · Tiếng Việt · ไทย · Bahasa Indonesia
- 처음 열면 **폰의 언어**를 따라가고, 오른쪽 위에서 바꾸면 기억됩니다. 해당 언어가 없으면 영어.

### 4.10 첫 방문 안내와 도움말
- 처음 들어가면 짧은 **사용법 안내**(탭해서 담기 → 꾹 눌러 듣기 → 배경화면 저장 → 카드 모양)가 나오고 **건너뛰기**할 수 있습니다. 페스티벌마다 한 번씩 나옵니다.
- "사용법 보기"로 다시 열 수 있습니다.

### 4.11 믿고 쓸 수 있게 알려 주는 것
- 시간표는 **공식 발표 기준**이며 현장에서 바뀔 수 있다는 안내가 항상 붙습니다. (일부 페스티벌은 이미지에서 읽은 값이라 5~10분 오차 안내)
- 사진·영상은 권리자(아티스트·주최측) 소유이며, **삭제 요청은 인스타그램 DM(@festlock)**으로 받는다는 안내가 있습니다.
- 로그인이 없고, 선택한 라인업은 폰에만 저장됩니다(크루 기능이 들어오면 7.3처럼 바뀝니다). 랭킹·다운로드 집계는 **익명 기기 번호**로만 세며 이름·연락처는 받지 않습니다.

## 6. 지금 알아둘 한계

- **사진이 없는 아티스트**는 이니셜 아이콘으로 나옵니다. 사진은 아티스트·주최측 제공 자료를 모은 것이라 모두 있지는 않습니다.
- **장르**는 공식 정보가 아니라 FestLock이 검색해 정리한 참고값입니다. `~`가 붙은 것은 특히 불확실합니다.
- 일부 페스티벌의 **종료 시각은 공식 표를 보고 짐작한 값**입니다(블록 길이).
- 인스타·카카오톡 **안 브라우저**에서는 이미지 저장·공유·오프라인 설치가 제한됩니다. 휴대폰 기본 브라우저로 여는 게 가장 안정적입니다.
- 드랍·영상은 **일부 아티스트만** 있고, 지역·권한에 따라 못 틀 수 있습니다(그럴 땐 YouTube로 안내).
- 오프라인은 **TML만**, **사진 없이**, 사용자가 저장한 뒤에만 됩니다. iPhone 실기기·Android 설치 버튼은 실제 폰에서 아직 확인하지 못했습니다.

### 7.3 크루(커뮤니티): 친구가 고른 아티스트를 카드에서 본다

**목표**: 같이 가는 사람들이 **누가 어떤 공연을 담았는지** 시간표에서 바로 보이게 한다. 같이 볼 공연을 정하고, 흩어졌다 만나는 약속을 쉽게 한다.

**용어**: **크루** = 같이 페스티벌에 가는 친구 모임. 한 사람이 여러 크루에 들어갈 수 있고, 페스티벌마다 따로 보입니다.

#### 카드 위의 친구 얼굴 (핵심 UI)
카드의 **위쪽 모서리**에 그 공연을 담은 크루원의 **얼굴 썸네일**이 작은 원으로 겹쳐서 나옵니다. 여러 명이면 **+N**으로 줄입니다.

| 그 공연을 담은 크루원 | 카드에 보이는 것 |
|---|---|
| 0명 | 아무것도 안 나옴 |
| 1명 | 얼굴 1개 |
| 2명 | 얼굴 2개가 살짝 겹침 |
| 3명 이상 | 얼굴 2개 + **+N** (N = 전체 − 2). 예: 5명이면 `+3` **[제안: 개수는 결정 필요]** |

- **위치**: 카드 오른쪽 위 모서리를 제안합니다. 왼쪽 위는 시간 표시가 쓰고 있고, 선택 체크 표시는 없앴기 때문에 오른쪽 위가 비어 있습니다.
- **크기**: 무대가 7곳이면 카드 폭이 **약 80px**입니다. 얼굴은 16~20px 원을 기준으로 하고, 겹치는 폭·+N 글자 크기를 이 폭에서 먼저 맞춥니다.
- **카드 모양 8종 모두에서** 잘 보여야 합니다. 사진이 카드 전체인 모양(모노 포토 등)에서는 사진 위에서도 얼굴이 구분되게 **흰 테두리 + 그림자**, 밝은 카드·어두운 카드 모두 대비가 나오게 합니다. 이름 글자나 아티스트 사진을 가리지 않는 위치여야 합니다.
- **헷갈리지 않게**: 아티스트 사진은 사각형/컷아웃이고, 친구 얼굴은 **항상 작은 원 + 테두리**로만 나옵니다. 내가 안 담은 공연에도 친구 얼굴은 보입니다(정보 용도). **내가 담은 공연의 "색이 켜짐"과 별개 층**으로 둡니다.
- **누르면**: 얼굴 묶음을 누르면 **"이 공연을 담은 친구"** 시트가 열려 이름·얼굴 목록과 **나도 담기** 버튼이 나옵니다. 작은 영역이라 눌리는 범위를 얼굴 크기보다 넓게(약 32px 이상) 잡거나, 카드를 꾹 눌러 여는 아티스트 창 안에 같은 목록을 함께 넣는 방안을 같이 둡니다 **[결정 필요]**.
- **접근성**: 화면 읽기에는 "친구 3명이 담았어요: ○○, △△, □□"처럼 읽히게 합니다. 얼굴만으로 구분하지 않도록 이름은 시트에서 확인.

#### 크루 만들기·들어가기·바꾸기
| 하는 일 | 방식 (제안) |
|---|---|
| 만들기 | 크루 이름을 정하고 **초대 링크(또는 코드)** 를 받음 |
| 들어가기 | 링크를 열거나 코드를 입력 → 닉네임·얼굴 사진 설정 → 합류 |
| 보기 전환 | 시간표 위쪽에 **크루 선택 칩**(예: `내 크루 · 4명 ▾`). 여기서 "친구 표시 켜기/끄기", 크루 바꾸기 |
| 나가기 | 크루 설정에서 나가기. 나가면 내 선택은 그 크루에게 더 이상 안 보임 |

크루 안에서 쓸 수 있는 보기(제안, **[결정 필요]**): **"크루가 고른 공연만 보기"**, **"나와 겹치는 공연"**(나도 담고 친구도 담은 공연에 작은 표시), 같은 시간대에 크루가 갈라지는 지점 알림.

#### 프라이버시와 계정 (UI에 직접 영향)
- 지금 서비스는 **로그인이 없고 선택이 폰에만 저장**됩니다(4.11). 크루를 하려면 **내 이름·얼굴·선택을 서버에 올리는 계정(또는 익명 번호 + 프로필)** 이 필요해서 이 안내 문구와 이용 약관·개인정보 안내가 **바뀌어야** 합니다.
- **기본은 꺼짐**이어야 합니다. 크루에 들어가고 "이 페스티벌의 내 라인업 공유"를 **직접 켠 사람만** 친구에게 보입니다. 페스티벌별로 켜고 끌 수 있고, 언제든 끌 수 있습니다.
- 내 선택은 **같은 크루원에게만** 보입니다. 크루 밖 사람에게는 보이지 않습니다. 얼굴 사진은 올리는 본인이 고르며, 올리지 않으면 이니셜 원으로 나옵니다.
- 미성년자·초상권·신고/차단은 **[결정 필요]**(크루원이 불쾌한 사진을 올렸을 때 등).

#### 오프라인과 크루
- 오프라인에서는 **마지막으로 받아 둔 크루원 선택**을 그대로 보여 주고, **"○○ 기준"** 시각을 함께 적습니다. 새 소식이 오면 연결 후에 갱신됩니다.
- 내가 오프라인에서 바꾼 선택은 연결되면 크루에 반영됩니다.

#### 빈 상태 · 오류 · 한계
| 상황 | 보여 줄 것 |
|---|---|
| 크루 없음 | "같이 가는 친구와 라인업을 맞춰 보세요" + **크루 만들기** |
| 크루는 있는데 아무도 안 담음 | 얼굴 없음. 상단에 "아직 담은 친구가 없어요" |
| 불러오기 실패 | 마지막으로 받은 내용 + "새 소식을 못 가져왔어요" |
| 크루원이 매우 많음 | 얼굴은 2개까지만, +N은 `99+`로 줄임. 최대 인원은 **[결정 필요]** |

#### 배경화면 이미지와의 관계 **[결정 필요]**
저장하는 배경화면 이미지에 **같이 가는 친구 얼굴**을 넣을지(스토리로 올리면 친구가 보이는 장점 / 초상권·개인정보 문제). 기본은 **넣지 않음**, 사용자가 옵션으로 켜는 방식을 제안합니다.

## 9. UI/UX 가이드라인 작성용 참고 (현재 화면의 사실)

> 가이드라인(디자인 원칙·컴포넌트 규칙)을 만들 때 **지금 서비스가 실제로 하고 있는 것**을 기준으로 삼을 수 있게, 코드에서 확인한 사실만 모았습니다. 새 기능(7장)은 아래 규칙 위에 얹습니다.

### 9.1 서비스 성격과 말투
- 비공식 **팬메이드**. 주최측과 무관하다는 안내와 "시간표는 공식 발표 기준, 바뀔 수 있어요"를 **항상** 보여 줍니다.
- 말투는 **친근한 존댓말(해요체)**: "탭하면 색이 켜져요", "잠시 뒤 다시 눌러 주세요". 실패해도 **사용자를 탓하지 않고** 다음 행동을 알려 줍니다(예: "저장이 안 돼서 이미지 뷰어를 열었어요. 이미지를 꾹 눌러 주세요").
- 모르는 정보는 **지어내지 않고 비워 두거나 `~`(추정) 표시**를 합니다(장르). 이 원칙은 새 기능에도 이어집니다(예: 크루에서 얼굴이 없으면 이니셜).

### 9.2 사용 상황 (디자인 제약으로 이어짐)
- **휴대폰 세로, 한 손, 현장**(밝은 야외·어두운 공연장 모두). 최대 폭 **560px**, 기준 폭 **약 360~430px**, 아주 좁은 폭(370px 이하)은 버튼 여백·글자 크기를 줄입니다.
- 아이폰 노치·홈 바 때문에 위·아래 **안전 영역**을 비웁니다. 아래 고정 바에 가려지지 않도록 아래 여백을 크게 둡니다.
- 느린/없는 신호를 전제로 합니다. 사진이 안 뜨면 이니셜, 영상이 안 되면 YouTube 안내로 **조용히 대체**합니다.

| **가로로 밀기** | 무대가 많을 때 옆 무대 보기 |
| **아래 고정 바** | "N팀 선택" · 초기화 · **배경화면 만들기** (한 화면에 한 가지 큰 행동) |
| **시트/팝업** | 아티스트 창, 배경화면 창, 랭킹, 겹침 목록, 카드 모양 고르기. ✕·바깥 터치·뒤로가기로 닫힘. 뒤로가기가 시트를 먼저 닫음 |
| **되돌릴 수 없는 일** | 한 번 더 누르게 함(초기화: "한 번 더 누르면 전체 삭제") |
| **알림** | 하단 토스트(저장됨/실패/공유 불가 등). 중요한 것은 팝업 |
| **연타 방지** | 같은 행동을 너무 자주 누르면 안내 팝업 후 잠시 집계만 멈춤(저장은 정상) |

### 9.5 화면·컴포넌트 목록
**화면**: 홈(페스티벌 목록) · 페스티벌 타임테이블(8곳) · 준비 중 페이지.
**타임테이블 안**: 상단 헤더(홈·언어) · 인트로 문구 · 칩 줄(카드 모양·거꾸로 보기·오프라인·사용법) · 날짜 탭(담은 수 배지) · 무대 헤더 · 시간 눈금 · **공연 카드(8모양)** · 겹침 안내 줄 · 아래 고정 바.
**시트·팝업**: 아티스트 정보 창 · 배경화면 만들기 창(미리보기·설정·저장/크게 보기/공유·👍👎) · 크게 보기 뷰어 · 랭킹 · 겹침 목록 · 카드 모양 고르기(미리보기) · 포스터 뷰어 · 오프라인 안내 시트 · 앱 안 브라우저 안내 · 이벤트 안내 · 앱 출시 안내(카드/저장 전 팝업) · 사용법 코치마크.

### 9.6 상태 목록 (가이드라인에서 각각 규칙이 필요한 것)
- **빈 상태**: 고른 공연 없음(배경화면 창), 시간표 준비 중, 랭킹 집계 없음.
- **불러오는 중/오류**: 랭킹 불러오기, 드랍/영상 재생 실패, 사진 없음(이니셜), 이미지 저장 실패(크게 보기로 전환).
- **환경별**: 앱 안 브라우저(인스타·카톡) 제한 안내, 오프라인(배지, 사진 없음, 일부 버튼 숨김), 라이트/다크, 모션 줄이기.
- **행사 상태**: D-day · 진행 중 · 종료(다시 보기) · 준비 중.
- **내 선택 상태**: 안 고름 / 고름 / 겹침 있음 / (새 기능) 친구가 고름.

### 9.7 다국어·글자 길이
- 9개 언어에서 **같은 자리가 깨지지 않아야** 합니다. 버튼·칩은 언어마다 글자 길이가 크게 달라서(예: 한국어 "초기화" vs 영어/스페인어 긴 단어) **고정 폭 대신 줄바꿈·말줄임 규칙**이 필요합니다.
- **아티스트 이름은 길이 제한이 없습니다.** 좁은 열(약 80px)에서 한 단어가 칸을 넘으면 글자가 끊기므로, 칸 폭에 맞춰 **글자 크기를 줄이고 단어 단위로 줄바꿈**합니다. 이름 글자가 얼굴을 가리지 않도록 **사진을 이름 높이만큼 위로 올립니다**(듀오톤).
- 한국어·일본어·중국어(간체/번체)는 글꼴이 달라서, 오프라인에서도 쓰도록 **언어별 글꼴을 따로 저장**합니다.

### 9.8 이미지(저장물) 규칙
- 출력 크기: **1080×1920(9:16)**, **1080×2280(9:19)**. 폰 잠금화면의 **시계 자리를 비우는 옵션**이 있어서, 위쪽 일정 영역에는 중요한 것을 두지 않습니다.
- 화면에서 보이는 카드 모양이 **저장 이미지와 똑같은 모양**이어야 합니다(미리보기 = 결과물). 새 요소(예: 친구 얼굴)를 화면에 더하면 **이미지에서도 어떻게 할지**를 같이 정해야 합니다.
- 사진·영상은 아티스트·주최측 소유이므로 **출처·삭제 요청 안내**가 화면에 남아 있어야 합니다.

### 9.9 접근성
- 칸은 하나의 버튼이며 "이름, 무대, 시간, 꾹 누르면 …" 식으로 읽힙니다. 시트는 대화상자로 열리고 ESC·뒤로가기로 닫힙니다.
- 색만으로 상태를 알리지 않도록 **"선택 N팀", "⚠ 시간 겹침 N곳"** 같은 글자 정보를 함께 둡니다. (체크 표시를 없앴기 때문에 **켜진 색의 대비**가 상태 표시의 전부입니다. 새 기능이 색을 더 쓰면 대비 기준을 같이 점검해야 합니다.)
- 작은 터치 영역: 무대가 많은 열에서는 요소가 작아지므로 **눌리는 범위는 보이는 크기보다 넓게** 잡습니다.
